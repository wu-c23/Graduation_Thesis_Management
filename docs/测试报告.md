## 1. 测试概述

本系统覆盖毕业设计过程管理的六步流程：需求文档、原型、设计评审、周报、代码仓库、测试报告。测试目标是验证：

1. 学生与导师的核心业务路径可完整走通；
2. 六步进度与导师总览统计口径一致；
3. 角色隔离、数据归属、文件访问控制有效；
4. 退回、重交、重复提交、同步失败等异常路径有明确处理；
5. 本地构建、启动与演示数据可复现。

## 6. 安全测试

| 编号 | 检查项 | 方法 | 结果 |
|---|---|---|---|
| S1 | 密码不以明文保存 | 检查种子数据与数据库写入 | 通过（BCrypt） |
| S2 | 未登录不能访问业务接口 | 不带 Token 请求受保护接口 | 通过（401） |
| S3 | 角色隔离 | 学生访问导师接口、导师访问学生接口 | 通过（403） |
| S4 | 数据归属隔离 | 学生访问他人材料、导师审核其他导师课题 | 通过（403） |
| S5 | 上传限制 | 非法扩展名、超限文件、非法外链 | 通过（400） |
| S6 | 下载鉴权 | 未登录、非本人、非名下学生下载文件 | 通过（401/403） |
| S7 | SQL 注入 | 全部查询使用 MyBatis-Plus 参数绑定；搜索在前端过滤 | 通过（代码审查） |
| S8 | 仓库 SSRF | 仅允许 GitHub/Gitee 主机，按白名单构造 API URL | 通过（代码审查 + 非法地址测试） |

补充说明：

- JWT 只从 `Authorization: Bearer` 读取，不写入 URL；
- 文件名清洗并 UUID 化，下载前校验路径必须位于上传根目录内；
- 开发默认 JWT 密钥仅用于本地演示，部署清单要求通过 `JWT_SECRET` 覆盖。

## 11. 遗留风险

| 风险 | 影响 | 建议 |
|---|---|---|
| 仓库公开 API 限流或网络异常 | 演示时同步失败 | 演示前先同步一次；失败时使用手工填写 |
| 前端包体积较大 | 首次加载略慢 | 答辩本地运行；后续可按需引入 Element Plus |
| MySQL 脚本未实测 | 后续切换环境需验证 | 部署前在真实实例执行并回归 |
| 未做性能测试 | 学生数增大后总览变慢 | 当前批量查询可控；规模扩大后再优化 |
| 无线上部署 | 无法远程演示 | 按运行说明本地启动，准备录屏备份 |
