## 3. 首次启动

### 3.1 启动后端

推荐使用根目录脚本：

```text
start-backend.bat
```

脚本会执行打包并启动 jar。等价命令：

```bash
cd backend
mvn -q -DskipTests package
java -jar target/thesis-platform-0.1.0.jar
```

> 项目路径含中文时，使用 `java -jar` 已验证可用；`mvn spring-boot:run` 可能因插件类路径编码报 `ClassNotFoundException`，不作为推荐命令。IDEA 中可直接运行 `ThesisApplication`。

首次启动会自动执行：

1. 读取 `backend/src/main/resources/schema.sql` 建表，并做幂等字段迁移；
2. 读取 `data.sql` 写入演示账号与课题；
3. 在 `backend/data/` 创建 H2 文件库。

健康检查：

```bash
curl http://localhost:8080/api/health
```

预期返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "UP",
    "database": "UP",
    "userCount": 3,
    "phase": "v1.0-final"
  }
}
```

### 3.2 启动前端

推荐使用根目录脚本：

```text
start-frontend.bat
```

等价命令：

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>。登录页顶部会显示后端健康状态。

也可以双击 `start-all.bat`，同时打开后端与前端窗口。

## 4. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `JWT_SECRET` | 开发默认密钥 | JWT HS256 签名密钥，部署时必须覆盖，长度至少 32 字节 |
| `UPLOAD_DIR` | 后端工作目录下的 `../uploads` | 材料上传根目录 |
| `SERVER_PORT` | 8080 | 后端端口（Spring Boot 标准变量） |

设置示例（PowerShell）：

```powershell
$env:JWT_SECRET = "please-change-this-to-a-32-byte-secret"
$env:UPLOAD_DIR = "D:\thesis-data\uploads"
```

> 开发默认密钥写在 `application.yml` 中，仅用于本地演示，不得用于任何公开环境。

### 5.2 前端构建

```bash

```

产物输出到 `frontend/dist/`。当前构建成功，仍有 Element Plus 全量引入导致的 chunk 体积提示，不影响运行。

### 5.3 端到端验收

端到端脚本会真实写入材料、周报、仓库与测试报告，**必须使用全新数据库**，不要对演示库重复执行：

```bash
cd backend
java -jar target/thesis-platform-0.1.0.jar \
  --spring.datasource.url='jdbc:h2:file:./target/w6db;MODE=MySQL;DATABASE_TO_LOWER=TRUE;AUTO_SERVER=TRUE' \
  --app.upload.dir=./target/w6-uploads
```

另开终端：

```bash
python scripts/acceptance-e2e.py
```

预期输出 `42/42 checks passed`。演示上传文件位于 `demo/`，用途见 `demo/README.md`。

### 5.4 前端产物预览

```bash
cd frontend
npm run preview
```

预览服务默认使用 4173 端口。注意：预览模式同样需要后端运行，且 `/api` 代理配置以开发服务器为准；若预览地址无法访问接口，请改回 `npm run dev` 联调。

## 6. 数据重置

演示前如需回到初始状态：

1. 停止后端；
2. 删除 `backend/data/` 下的 H2 文件；
3. 删除 `uploads/` 下需要清理的课题目录；
4. 重新启动后端，建表脚本与种子数据会自动重跑。

> H2 文件库同一时间只能被一个进程打开。若启动报数据库被占用，先关闭其他后端进程。

## 8. 关于部署

**当前未部署到任何服务器。** 原因：课程环境暂无可使用的服务器，按任务要求不执行线上部署。

计划部署时（不在本次交付范围内），需要补齐以下事项：

| 事项 | 说明 |
|---|---|
| 运行环境 | 安装 JRE 21，打包后的 jar 可直接运行 |
| 反向代理 | Nginx 托管 `frontend/dist/`，将 `/api` 转发到后端 |
| 密钥 | 通过环境变量设置强随机 `JWT_SECRET`，关闭开发默认值 |
| 数据库 | 如需 MySQL，执行 `db/schema-mysql.sql` 与 `db/data-mysql.sql`，切换数据源 |
| 上传目录 | 指定持久化磁盘路径，配置备份 |
| 端口与防火墙 | 只对外开放 80/443，8080 不直接暴露 |
| H2 控制台 | 关闭 `spring.h2.console.enabled`，或仅限内网 |
| 日志与备份 | 配置日志轮转与数据库、上传目录定期备份 |

以上均为后续部署清单，本次未执行，也不在本报告的验证结论之内。
